## v3: character portraits (painted), avatars and clue scenes
- **Character portraits** (`assets/img/chars/*.webp`, 10 characters x 5 expressions + thumbnails, and the wanted-poster paper `poster_bg.webp`): **original AI-generated art made for this project**, in a painted graphic-novel style. They depict **fictional people** (Professor Pelican, Ranger Rosa, Ranger Dee, Mr. Okafor, Guide Tomás, Detective Sam, Penny Pinch, Rusty Hinges, Captain Fogbottom, Lulu Larceny), not any real person. Made with the Grok Imagine image tool from a project style reference (`art-src/penny_style_ref.jpg`, supplied by the project owner); each expression was generated from that character's own neutral image. Full-size originals are in `art-src/` (not shipped in the game). Changes: resized to 450x600 and a 150x200 thumbnail, WebP quality 65-68.
- **SVG fallback portraits** (`js/portrait.js`, `js/characters.js`): drawn in code for this game; used only if a painted image is missing.
- **Detective avatar parts** (skins, hair, hijab, glasses, hearing aid, outfits, hats, gear): the same self-made SVG engine, with a painted paper texture and soft shading added in CSS (an SVG noise filter drawn in code) so avatars sit closer to the painted cast.
- **Dust layer** on the Founding Stone: generated live on a canvas.
- **Hotspot / magnifier scene** uses the existing `castillo_room` photo (credited above). **Torn-map puzzle** slices the existing `gibson1763` map (Library of Congress, public domain) with CSS.
- Nothing was bought or added from third parties for v3.


## v5: painted kid detectives and ID-card backdrops
- **Detective portraits** (`assets/img/avatars/*_{neutral,happy,surprised}.webp` and `thumbs/`, 24 fictional children × 3 expressions): **original AI-generated art made for this project**, in the same painted graphic-novel style as the v3 character portraits (tan trench coat, cream studio backdrop, head-and-shoulders framing). They depict **made-up 8-to-10-year-old detectives**, not any real person or copyrighted character. Each expression was generated from that detective's own neutral image. Full-size originals are in `art-src/avatars/` (not shipped in the game zip). Changes: resized to 512×512 and a 160×160 thumbnail, WebP quality ~80 / ~75.
- **ID-card backdrops** (`assets/img/avatars/bg_coquina.webp`, `bg_mangroves.webp`, `bg_oaks.webp`, `bg_beach.webp` and thumbnails): original painted (not photographic) Florida-themed backgrounds made for this project with the same image tool. Changes: resized WebP derivatives.
- The in-game Detective ID card, circular badge icons, and stamp are drawn in code (`js/avatars.js`, `v3.css`). Costume pieces earned from badges appear as badge icons on the card, not as hats composited onto the painted heads.
- Older saved profiles that still have SVG avatar settings are mapped to a close painted detective; players can change the pick in My Detective. The SVG portrait engine remains as a fallback if a painted file is missing.
- Nothing was bought or added from third parties for v5.

## v7: The Swamp Fox Heist and sound

- **The Swamp Fox, Gator Gil and Minnow** (`assets/img/villain/*.webp` and `_s` thumbnails): **original AI-generated art made for this project**, in the same painted graphic-novel style as the v3 character portraits and v5 kid detectives (style reference `art-src/penny_style_ref.jpg`). They depict **fictional people**, not any real person or copyrighted character. The Swamp Fox is a sly, kid-safe thief (raccoon-style eye mask, alligator-scale vest). Gator Gil is her clumsy helper. Minnow is a short adult lookout (not a child). Full-size originals are in `art-src/villain/` (not required to play). Changes: resized so the longest side is 512px (calling card 640px wide) and a 180px thumbnail, WebP quality ~80 / ~72.
  - `fox_taunt.webp` — smirking with a calling card
  - `fox_run.webp` — running away with a historic cannon (story loot; not aimed as a weapon)
  - `fox_caught.webp` — surprised, comic “caught” pose
  - `fox_mugshot.webp` — front-facing mugshot with a height chart and a “SWAMP FOX” placard
  - `fox_card.webp` — blank painted calling-card template (letterhead only; note text is HTML)
  - `gil_neutral.webp`, `gil_oops.webp` — Gator Gil
  - `minnow_lookout.webp`, `minnow_nervous.webp` — Minnow
- **Story treasures** (a Castillo cannon, a Fort Mose replica militia drum, a Mission San Luis replica church bell) are made up for the chase. The places and the history around them are real: the Castillo de San Marcos really has historic cannons; Fort Mose’s free Black militia helped defend St. Augustine; in 1704 the people of San Luis buried church bells, hoping to return. See FACT_CHECK.md for sourced facts already used in the case.
- **Music and sound effects**: original, self-made synthesis created in the game with the Web Audio API (`js/sound.js`). No recorded audio files, no third-party samples, nothing to license. Music ducks while read-aloud (the device’s built-in Web Speech API voices) is speaking.
